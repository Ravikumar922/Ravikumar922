Each finished project will aim to explain:

1. **Business question** — what needs to be understood and why
2. **Data** — source, definitions, and any privacy considerations
3. **Method** — cleaning steps, queries, calculations, and assumptions
4. **Findings** — what the analysis shows
5. **Recommendations** — practical next steps, including limitations

I’ll use public or synthetic data and won’t publish confidential company or employee information.
